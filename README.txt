TREE FAMILY - ASP.NET WEB FORMS .NET FRAMEWORK 4.8

Cara menjalankan:
1. Extract seluruh ZIP ke folder biasa.
2. Buka TreeFamily.sln di Visual Studio 2022.
3. Pastikan workload ASP.NET and web development dan .NET Framework 4.8 Developer Pack terpasang.
4. Set TreeFamily sebagai Startup Project.
5. Jalankan dengan F5.

Catatan:
- Default.aspx memakai markup, CSS, dan JavaScript asli dari index.html.
- Library html2canvas dan jsPDF serta gambar lokal disertakan.
- Fungsi utama tree, interaksi browser, dan ekspor tetap client-side.
- Project diarahkan ke IIS Express dan URL localhost:5000; ubah port jika sudah dipakai.
- Build aktual perlu diverifikasi di Visual Studio Windows.
